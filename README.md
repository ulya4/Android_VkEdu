# Android VK Education

Учебный Android-проект на Kotlin и Jetpack Compose.

## Задания и ветки

| Часть проекта | Ветка | Что находится внутри |
|---|---|---|
| Стартовый проект | `master` | Базовое приложение с экраном `Hello Android` |
| Практическое задание 3 — Intents | `homework-3-intents` | Две Activity, передача текста, набор номера и меню «Поделиться» |

(Задание 3 хранится в отдельной ветке и не сливается в `master`).

## Основные файлы

- `MainActivity.kt` — главный экран. В ДЗ 3: поле ввода и три кнопки.
- `SecondActivity.kt` — второй экран, отображающий полученный текст (только в ДЗ 3).
- `AndroidManifest.xml` — регистрация Activity.
- `ui/theme/` — оформление приложения.
- `app/build.gradle.kts` — настройки и зависимости проекта.

## Задание 3. Работа с Intent

1. **Явный Intent:** передача текста между Activity.
2. **Неявный Intent (`ACTION_DIAL`):** открытие приложения для звонков.
3. **Системный Intent (`ACTION_SEND`):** системное меню «Поделиться».
4. **Валидация:** сообщение при пустом поле ввода.

Ветка: `homework-3-intents`.
